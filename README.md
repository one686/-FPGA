# 插卡即播数字广告牌系统

基于安路 EG4S20（HX4S20C 开发板）的 HDMI 多媒体广告播放终端。不使用处理器和软核，读卡、FAT32 解析、BMP 解码与缩放、帧缓存调度、画面合成和 HDMI 音视频编码全部由 Verilog 硬件流水线完成。固化到 Flash 后，接上显示器、插入 TF 卡，上电即播。

## 主要功能

- **插卡即播：** 自动识别 TF 卡根目录的 PICn.BMP（最多 12 幅）、WAV 配乐（最多 12 首）和 SUB.BMP 滚动标语，换卡即换内容；
- **任意尺寸缩放：** 24 / 32 位 BMP，每边最大 1920 像素，缩小用区域平均，放大用 Catmull-Rom 双三次，等比适配 640×480 并居中补黑边；
- **6 帧缓存调度：** 两级保护、后台预取、按键插队，已缓存图片下一帧切换；写帧时同步生成缩略图，供胶片条浏览；
- **画面效果：** 5 种转场（淡入淡出、擦除、推移、百叶窗、中心展开）及依次轮换；亮度、对比度、饱和度、色温各 11 档；抗锯齿 OSD 和卡上滚动标语；
- **音频：** 自研 HDMI 数据岛编码，48 kHz WAV 播放；32 段四阶常 Q 滤波器组驱动音浪和 64 柱全屏可视化；轮播可选"随音乐"档，一首歌播完换一幅；
- **免值守运维：** 坏图、坏歌自动跳过，读卡故障自动恢复，数码管与 OSD 显示错误码；定时关机时关闭 TMDS，显示器随之待机，按任意键唤醒续播。

资源：LUT 17163 / 19600（87.57%），BRAM 76 / 80，DSP 28 / 29，PLL 1；时序全部收敛（Setup +0.511 ns，Hold +0.021 ns）。

## 使用方法

1. **打开工程：** 用 Tang Dynasty 6.2.1 打开 `src/td_project/HDMI1.4b_Transmitter_v1.0.al`，器件 EG4S20BG256。源文件都是相对路径，拷到任意目录都能打开、重新综合和布局布线。
2. **下载 / 固化：** 用 TD 的下载工具把 `best_result/HDMI1.4b_Transmitter_v1.0.bit` 烧写到配置 Flash，之后上电自动运行。
3. **准备 TF 卡：** 格式化成 FAT32，根目录放 `PIC1.BMP`~`PIC12.BMP`、48 kHz / 16 位的 WAV（可用 `wav_to_48k.py` 转换）和 `SUB.BMP`（可用 `make_subtitle.py` 生成）。
4. **连接：** HDMI B 口接显示器（显示器建议设成 4:3 或点对点），USB 供电，插卡上电。

## 操作速查

| 控件 | 图片层（SW4 拨下） | 音乐层（SW4 拨上） |
|---|---|---|
| KEY1 | 短按：胶片条；按住 3 s：系统复位 | 短按：全屏可视化；按住 3 s：系统复位 |
| KEY2 | 下一张 | 短按下一首；长按上一首 |
| KEY3 | 短按：切换显示模式；长按：画面调节菜单 | 短按音量 +；长按音量 − |
| KEY4 | 短按：自动轮播；长按：上一张 | 短按暂停；长按单曲循环 |
| SW1~SW3 | 选转场效果 | 同左 |

数码管从左到右：第 1~2 位当前张号，第 3~4 位总张数，第 5~6 位曲号，第 7 位错误码，第 8 位状态（L 加载 / A 自动轮播 / P 暂停）。详细说明见技术文档。
